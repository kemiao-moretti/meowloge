## 变更详情

### 摘要卡片

- 文章 front matter 存在 `ai_summary` 时，在正文前渲染摘要卡；没有该字段的文章不输出任何占位内容
- 卡片包含图标标题、右侧模型标签与摘要正文，配色、圆角与描边全部复用 `--efu-*` / `--candy-*` 主题令牌，明暗模式自适应
- 摘要默认带打字机效果，浏览器开启「减少动态效果」时直接显示全文
- 移动端与超窄屏下模型标签自动换行并截断，不产生横向滚动
- 模板只读取 `.Params.ai_summary` 与站点 `params.solitude.ai_summary` 配置，旧文章无需批量修改

### 摘要生成脚本

- 新增 `scripts/generate-ai-summary.mjs`：遍历 `content/posts/` 下的 Markdown，把生成的摘要写回 front matter
- 使用 OpenAI 兼容的 Chat Completions 接口，默认对接 SiliconFlow 的 `Qwen/Qwen3-8B`
- 发送前清理正文：剥离 front matter、代码块、图片与链接地址、HTML 标签与 Markdown 符号，并按输入上限截断（默认 12000 字符）
- 默认跳过已有摘要的文章，`--force` 或 `AI_SUMMARY_COVER_ALL=true` 可覆盖；`--dry-run` 只列出待处理文章不写文件
- 支持并发数、处理间隔、自定义摘要字段与自定义提示词
- Qwen3 默认开启的思考模式已固定关闭（`enable_thinking: false` 且 `stream: false`），直接返回普通 JSON 摘要
- 单篇请求失败只记录文件名与原因并继续后续文章，不会写入半截摘要；存在失败项时返回非零退出码

### 密钥与构建流程

- 接口地址、密钥与模型名统一从博客根目录 `.env` 读取，提供 `.env.example` 示例并把 `.env` 加入 `.gitignore`
- 终端已有的同名环境变量优先于 `.env`，可临时覆盖而不改动文件
- 摘要生成与站点构建保持分离：`hugo` 不会调用 AI 接口，需要更新摘要时先运行脚本再构建，发布过程可控

### 配套适配

- 摘要组件接入主题 PJAX 生命周期：切页前清理打字机定时器，切页后重新初始化，避免定时器泄漏与半截文本残留
- 新增一篇接入说明文章，记录组件位置、配置项、脚本用法与常见错误排查
