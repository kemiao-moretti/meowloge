## 视觉重构

- 使用 Solitude 上游布局与功能结构作为基础，统一引入纸张手账设计令牌
- 参考 FlatPaper Demo 的纸张质感、正文排版和手账元素
- 引入暖纸色、网格纸、横向纸纹、轻阴影、胶带和不规则纸张边角
- 文章卡片、侧栏卡片、导航、代码块、归档和特殊页面统一使用纸张语义令牌
- 统一收敛全站纸张手账视觉，避免不同页面之间的风格割裂

## 导航与组件优化

- 将导航链接、站点名称、首页分类栏、标签栏和下拉子菜单从胶囊形改为矩形小圆角
- 将返回首页菜单、滚动导航、页面标题和上一篇 / 下一篇分页统一为纸张卡片背景
- 将音乐播放器及其控制层改为矩形纸张组件，保留原有播放、进度和悬停交互
- 优化个人资料卡片的纸张装饰，修复卡片上方书签被父容器裁切的问题
- 保留文末打赏在桌面悬停、触屏点击和键盘聚焦下的展开行为

## 明暗模式适配

- 亮色与暗色分别定义纸张画布、表面、文字、边框和强调色，切换时不依赖硬编码覆盖
- 统一使用 `--paper-*` 与 `--efu-*` 语义变量，不在组件中硬编码明暗模式颜色
- 修复浅色模式下返回顶部、个人资料卡片和导航组件仍显示深色背景或白色文字的问题
- 修复深色模式下滚动导航、分页、音乐播放器和侧栏组件背景不一致的问题
- 参考 Solitude 原生导航状态链，覆盖中控台默认、悬停、聚焦和打开状态
- 修复文章页、音乐页中主题原生规则对中控台图标颜色的强制覆盖
- 浅色模式中控台图标使用强调色，深色模式使用纸张文字色，鼠标悬停后保持一致

## 动效与兼容性

- 通过 `prefers-reduced-motion` 为减少动态效果的用户关闭过渡动画
- 保留 Solitude 的响应式布局、PJAX、搜索、评论、音乐和菜单功能
- 未修改现有 API 地址、端口配置及第三方服务配置
- Hugo 构建、首页、文章页和音乐页的明暗模式及中控台交互均完成验证
