## 移动端导航

### 紧凑顶栏

- `≤1024px` 的首页、文章页、归档、分类、标签、友链与普通页面统一使用固定顶栏
- 移动端隐藏站名文字，保留首页图标，避免功能按钮过多时发生挤压
- 左侧新增独立的站点导航入口，读取 `hugo.yaml` 中 `params.solitude.nav.group` 的分组链接
- 右侧按「搜索 → 中控台 → 目录 → 回到顶部 → 菜单」排列，目录入口只在当前页面存在目录时显示
- 桌面端 `>1024px` 的站名、主导航、左上角快捷分组和原有右下角按钮保持不变
- 移动端菜单图标统一按钮尺寸与视觉基线，修复 bars 图标低于其它按钮的问题
- 浅色模式下移动顶栏使用纸张主题变量，避免浅色背景上出现白色图标或文字

### 双侧导航面板

- 左侧站点导航面板独立展示“主页 / 项目”等外部快捷链接
- 右侧菜单面板继续复用项目原有的手机端侧栏，保留统计、显示模式、主导航、标签云和站点信息
- 两个面板互斥打开，分别从左侧和右侧进入
- 支持遮罩、关闭按钮、`Esc` 和页面跳转后自动关闭
- 打开面板时锁定页面滚动，关闭后恢复原来的滚动状态

## 阅读与交互优化

### 目录面板

- 移除底部与音乐播放器并列的 `#toc-fab` 悬浮目录按钮
- 目录入口迁移到移动端顶栏
- 目录面板改为从顶栏目录按钮下方展开，动画起点位于右上角目录按钮附近
- 保留目录层级高亮、内部滚动、遮罩和滚动锁定

### 音乐播放器

- 移动端未播放时收起为左下角圆形播放按钮，减少底部占位
- 播放后展开为完整音乐胶囊，暂停后重新收起
- 打开目录、菜单、中控台或搜索时，音乐播放器降到遮罩下方并暂时不可点击
- 桌面端音乐播放器的原有尺寸和交互不变

### 中控台

- 移动端不再隐藏中控台内容卡片
- 手机端以纵向可滚动布局展示最近评论、标签、归档和操作按钮
- 内容与桌面端使用同一套数据和模板
- 浅色模式下中控台按钮默认与搜索、随机文章使用普通按钮色，只有打开后才进入强调色状态

### 回到顶部

- 移动端滚动后显示回到顶部按钮
- 恢复与桌面端一致的滚动百分比显示
- 页面位于顶部时按钮自动收起

## Atom 订阅

### Atom 1.0 输出

- 订阅输出从 RSS 文件名方案切换为真正的 Atom 1.0
- 首页、栏目、分类与标签订阅统一生成 `atom.xml`
- Atom 文档包含标题、描述、作者、发布时间、更新时间、摘要、正文、分类、系列和标签
- 带有文章封面的条目输出 Atom enclosure 链接
- 更新页头 alternate 链接、页脚订阅入口、友链申请表单中的 feed 地址和文章订阅配置

### 浏览器订阅页

- 新增 `static/atom.xsl`，参考 `hexo-pretty-feed` 和 LiuShen 的 Atom 页面设计
- 直接打开 `atom.xml` 时显示纸张手账风格的订阅页面，而不是原始 XML
- 页面包含站点标题、描述、文章数量、最近更新时间和订阅地址复制按钮
- 文章卡片显示封面、标题、发布时间、更新时间、摘要、分类、系列和标签
- 有封面的文章使用图文卡片布局，没有封面的文章自动使用无图布局
- 适配移动端窄屏，并支持系统浅色 / 深色模式
- 订阅器读取的仍是标准 Atom 数据，不影响 Feedly、Inoreader 等阅读器使用

### 摘要清理

- Atom 卡片摘要改为纯文本输出，移除正文中的 HTML 标签
- 摘要源头限制为约 220 个字符，避免代码块、标题和长正文撑高卡片
- XSL 页面在桌面端和移动端继续使用行数限制，保证文章列表紧凑
- Atom 的 `content` 仍保留完整 HTML，订阅器需要阅读全文时不受影响

## 兼容性

- 桌面端原有导航、按钮、侧栏和播放器行为保持不变
- Atom 数据格式与浏览器 XSL 展示层分离，XSL 不可用时仍可直接读取标准 XML
- 移动端面板支持键盘 `Esc`、可见焦点和减少动态效果设置
- 所有样式继续使用项目现有纸张主题变量与响应式布局，不引入固定页面宽度
