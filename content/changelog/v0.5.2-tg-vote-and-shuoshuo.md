## Telegram 数据源

- 说说页新增 `tg` 数据源，接入自托管的 koharu-suite Telegram API。
- 支持按 Telegram 频道拉取消息，并复用主题现有的瀑布流卡片布局。
- 支持 Telegram 正文 HTML 与 Markdown 两种渲染模式，可在 `hugo.yaml` 中配置。
- 支持 Telegram 图片媒体、附件、原文链接和频道信息展示。
- 支持隐藏正文开头或结尾用于分类的连续 Hashtag，同时保留标签栏和标签筛选功能。
- 支持 Telegram 消息搜索和 RSS 订阅入口，仅在启用 `tg` 数据源时显示。
- Telegram 卡片显示名称支持通过 `hugo.yaml` 自定义配置。

## 文章投票

- 文章页接入自托管 `star-vote` 投票服务。
- 支持文章进行 1—5 星评分。
- 投票配置统一放在 `hugo.yaml`，可独立控制投票功能和服务地址。
- 投票组件继续使用主题现有的卡片布局、颜色变量和响应式样式。

## 说说点赞与踩

- Telegram 说说卡片新增点赞和踩功能。
- 使用 Telegram 消息 ID 作为稳定投票标识，分页、搜索后仍对应同一条消息。
- 显示点赞与踩的实时数量。
- 使用本地存储记录当前浏览器的投票状态，避免重复操作。
- 搜索结果中的 Telegram 说说卡片同样支持点赞和踩。
- 投票接口异常时不影响说说正文、媒体和评论功能。

## 安全与兼容性

- Telegram HTML 内容经过 DOMPurify 净化后再渲染，避免远程内容直接注入脚本。
- Memos 和 Ech0 数据源保持原有行为，不会加载 Telegram 搜索、RSS 或投票接口。
- 继续使用主题已有的 CSS 变量、间距、圆角和瀑布流布局，避免新增硬编码页面样式。
- 已通过 Hugo 构建检查，并在本地 `1313` 端口验证 Telegram 卡片、搜索和投票控件输出。
