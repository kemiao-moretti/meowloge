## 变更详情

### 赞助申请与审核工作流

- 新增赞助申请 Issue 表单（sponsor.yml）：填写名单名称、赞助金额、赞助日期与支付截图链接四个必填项，标题带 `[赞助申请]` 前缀并默认打上 `赞助申请` 标签
- 表单内明确隐私边界：支付截图仅用于站长审核核对，不写入公开名单
- 新增独立的赞助审核工作流与数据处理脚本：仅在议题「已关闭 + 含 `赞助申请` 标签 + 不含 `赞助失败` 标签」时，把名单名称、金额、日期追加到 `/about/` 的赞赏名单末尾
- `赞助失败` 标签优先阻断：存在该标签时不修改任何名单数据，并回写未通过的说明评论
- 以议题编号做幂等判断，同一议题重复触发不会重复追加；仅在数据真正变化时才提交变更
- 审核通过后自动回写成功评论并保持议题关闭；未关闭的议题只提示「审核待生效」，不改动数据

### 关于页赞助组件

- 新增手机端通栏「为 TA 充电」按钮：坐在赞助声明与赞赏名单之间，点击弹出微信 / 支付宝收款码
- 桌面端保持原有的闪电按钮与连接动画不变；手机端按钮文案由独立配置项控制，未配置时自动回退
- 赞助联系渠道由邮箱改为 GitHub Issue：声明文案改为「通过 GitHub Issue 提交申请」并新标签页打开，原邮箱保留为回退

### 说说页多图体验

- 多图说说改为智能网格布局：单图通栏限高、两图两列、三图及以上统一三列方形缩略
- 超过 9 张自动折叠，末格叠加「+N」遮罩，点击可原地展开全部图片与收起，避免长图堆叠把卡片撑高
- 正文内联图片统一抽离到网格并去重，图片失效时显示占位，点击缩略图进灯箱浏览原图
- 兼容多种图片来源：外链、协议相对地址、`data:` / `blob:` 内联图均正常解析

### 说说页标签去重

- Memos 的标签由正文 `#标签` 解析而来，此前正文文本与卡片底部标签 chip 会重复显示
- 现在自动隐藏正文「开头或结尾」与标签字段匹配的 `#标签` 文本，正文中的普通井号表达不受影响
- 卡片底部的可点击标签保持不变，标签筛选与分页行为不受影响；仅对 Memos 数据源生效
