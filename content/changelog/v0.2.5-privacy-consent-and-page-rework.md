## 变更详情

### Cookie 同意弹窗

- 页面底部新增 Cookie 使用说明弹窗，提供「接受全部」与「拒绝非必要」两个选择
- 选择结果写入 `solitude_cookie_consent` Cookie，携带版本号、一年有效期、`Path=/` 与 `SameSite=Lax`，HTTPS 下自动附加 `Secure`
- 已做出选择的访客不再重复弹出；版本号变化时旧选择自动失效并重新询问
- 弹窗使用 `role="dialog"` 与 `aria-labelledby` / `aria-describedby`，隐藏态走 `hidden` 属性而非仅靠 CSS
- 文案接入多语言（简体 / 繁体 / 英文 / 西班牙文），配色与圆角全部复用主题令牌，明暗模式自适应

### 隐私说明页重构

- `/privacy/` 重写为结构化说明页，按「说明范围 / 处理哪些信息 / Cookie 与本地存储 / 访问统计 / 第三方资源 / 评论与主动提交 / 你的选择与权利 / 联系站长」分章
- 页首新增状态摘要卡：站点统计与评论服务是否启用，直接读取配置文件中的 Umami 与评论设置，不写死
- 左侧锚点导航跟随滚动高亮，移动端可折叠，长页面也能快速跳转
- 明确声明不做用户画像、不出售数据，并列出可行使的权利与撤回方式
- 隐私页自身关闭侧栏与目录，避免与锚点导航重复

### 404 页面重做

- 404 页改为纯 CSS / 纯文字实现，不再依赖静态图片素材
- 新增主标题、说明文案、品牌贴纸与「返回首页 / 返回上一页」双按钮，返回上一页在无历史记录时回退到首页
- 页面底部展示最近 3 篇文章推荐，是否展示由配置项控制
- 标题、文案、品牌标记与推荐开关均在站点配置中可调，未配置时回退多语言文案

### 交互自由

- 新增按住 `Ctrl` + 右键使用浏览器原生菜单的开关，不再拦截事件
- 首次触发时用提示条说明一次该操作方式，之后不再打扰
- 未按住修饰键时保持原有的自定义右键菜单行为不变
